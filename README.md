# 은퇴 계산기 모음 — 초안

이 저장소에는 단일 HTML 계산기 두 개가 있어요. 빌드나 설치 과정 없이 파일을 브라우저에서 열면 돼요.

| 파일 | 계산기 |
|---|---|
| `index.html` | 연금 계산기 (IRP · 퇴직연금) |
| `retirement-asset-calculator.html` | 부부 은퇴자산 계산기 |

---

## 연금 계산기 (IRP · 퇴직연금)

IRP와 퇴직연금을 연금으로 받을 때 해마다 얼마를 받는지 계산하는 단일 HTML 시뮬레이터예요. 금액은 실질금액(기준 연도 가치)을 중심으로 보여주고, 괄호 안에 명목금액을 함께 표시해요.

### 사용법

`index.html`을 브라우저에서 열면 돼요. 빌드나 설치 과정은 없어요.

### 기능

- **탭 3개:** IRP 연금 계산기, 퇴직연금 계산기, 합산 결과
- **공통 정보:** 기준 연도, 물가상승률, 본인·배우자 출생연도, 연금 세금 설정
- **납입·적립 기준과 수령 방식:** 각각 동일 실질금액과 동일 명목금액 중에서 고를 수 있어요.
- **세전·세후 계산**
  - 나이별 연금소득세율(5.5% / 4.4% / 3.3%)
  - 1인당 저율과세 한도(실질 기준). 한도를 넘으면 16.5% 분리과세나 종합과세 중 선택
  - 연금수령한도(처음 10년)와 연금외수령 과세
  - IRP: 세액공제를 받지 않은 비과세 원금을 먼저 인출
  - 퇴직연금: 퇴직소득세 70%(11년차부터 60%) 감면, 운용수익은 연금소득세
- **합산 결과:** 두 연금을 합쳐 1인당 저율과세 한도를 다시 따져 세금을 계산하고, 연도별 합계를 보여줘요.
- **계산하기 버튼:** 누를 때만 계산해요.
- **탭별 저장 버튼:** 입력값을 브라우저 localStorage에 저장해요.

### 한계

이 계산기는 단순 가정에 따른 시뮬레이션이에요. 건강보험료와 세법 개정은 반영하지 않았어요. 실제로 연금을 받기 전에 최신 세법과 금융회사 안내를 확인하세요.

## 부부 은퇴자산 계산기

부부가 은퇴 후 원하는 생활비를 기대수명까지 쓰려면 은퇴를 시작할 때 얼마가 있어야 하는지 계산해요. 입력과 결과는 모두 현재 가치(오늘 물가 기준)예요.

### 사용법

`retirement-asset-calculator.html`을 브라우저에서 열고 값을 넣은 뒤 **계산하기**를 누르면 돼요. 금액은 만원 단위이고, 집 가격과 주택 대출만 억원 단위예요.

### 기능

- **본인·배우자 따로 입력:** 나이, 은퇴 나이, 기대수명, 월 소득, 국민연금 예상 월액, 수령 시작 나이
- **가구 공동 입력:** 현재 금융자산, 월 저축액과 연 증가율, 은퇴 전·후 수익률, 물가상승률
- **거주 주택과 대출:** 지금 집과 은퇴 후 살 집의 가격·대출·금리·상환 기간을 넣으면 순자산(집값 − 대출)으로 계산해요. 대출은 원리금균등 상환이에요.
- **생활비 옵션:** 혼자 남았을 때 생활비 비율, 유족연금 반영, 생활비에 대출 상환액 포함 여부, 남기고 싶은 자산, 은퇴 후 실질 자산 유지
- **결과:** 필요 자산(집 포함)과 예상 자산, 부족액, 부족을 메울 추가 월 저축, 자산 고갈 나이
- **은퇴 후 월 현금흐름:** 금융자산 + 국민연금 + 기타 소득을 목표 생활비와 비교하고, 기간별로 나눠 보여줘요.
- **은퇴 일정, 나이별 금융자산 그래프, 가정별(물가·수익률 ±1%p) 필요 자산 표**
- **시나리오 저장:** 계산 결과를 이름 붙여 저장하고 불러올 수 있어요. 이 파일을 직접 열면 브라우저 localStorage에 저장돼요.

### 한계

연 단위로 단순화한 시뮬레이션이에요. 세금, 건강보험료, 큰 일시 지출은 반영하지 않았고, 유족연금은 단순화한 규칙으로 계산해요. 은퇴 이후 집값 변화도 반영하지 않아요. 실제 계획은 최신 제도와 전문가 상담으로 확인하세요.
